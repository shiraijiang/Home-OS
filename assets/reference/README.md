## 当前状态

以上三张图片均已于 2026-08-11 入库，路径均为 `assets/reference/`。

进行 Home-OS 美术任务时必须读取实际参考图片，并同时遵守 `docs/04-art.md` 与 `assets/prompts.md`。不得自行寻找替代参考图，也不得根据文字描述重新生成所谓“母版”。

## 参考图只约束画面，不约束功能

图上如果带有文字图例、入口说明、时间 / 季节示例条，那些只是出图当时的说明稿，**不构成规格**（#74）。

- 参考图约束：构图、镜头、透视、房间边界、家具位置与比例、像素语言。
- 不约束：入口、功能、时间段数、季节表现——这些一律以 `docs/` 为准。
- Base 出图时不得把说明栏画进画面。
