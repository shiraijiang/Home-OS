# Home-OS 美术提示词约束

本文件不是一条固定生成提示词，而是所有 Home-OS 美术生成 / 修改都必须继承的约束集合。真正执行前仍需读取 `docs/04-art.md` 和 `assets/reference/` 中的实际参考图。

## 必须保持

- high-detail pixel illustration
- 手机竖屏逻辑场景 320×420，工作母版 1280×1680
- 俯视带前倾，家具可见顶面 + 正面
- 仅后墙完整出现，左右在画面边缘切断
- 大房间概念图决定镜头、透视、空间结构、主要家具位置和比例
- 小房间像素参考图只决定像素粗度和信息密度，不带入其户型
- 清水混凝土、深色不发黄木、不锈钢、玻璃、铁艺
- 赛璐珞式平涂，硬边，少量明确像素高光
- 木材不画细密连续木纹，混凝土/地砖不铺高频噪点，植物使用像素簇

## Base 生成 / 修改

Base 必须是中性版本：

- 所有室内灯关闭
- 不出现方向性阳光、窗格投影、长投影
- 不出现具体时间或季节性的窗外景色
- 只保留轻微接触阴影
- 不画猫、扫地机器人、小精灵、钥匙、鞋、衣服、随身包、饮料、酒、杯子、食物、散落猫玩具
- 不画电子设备的具体动态时间

固定保留：建筑结构、厨房、独立冰箱、岛台/吧台、玄关/鞋柜、衣架/开放式置物架、卧室入口、右侧玻璃结构、扫地机器人充电座、固定盆栽、鱼缸主体与造景、固定猫用品、水槽旁洗洁精。

右侧不要新增小矮柜，不要在地上靠墙放画。

## Dynamic

猫、扫地机器人、黄色小精灵、钥匙、鞋、衣服、随身包、饮料/酒、散落猫玩具等必须独立于 Base。

动态资源必须和 Base 使用同一像素粗度与信息密度，不得更精细。

## 时间变化

不能只给整张图套滤镜；必须由 Environment + Lighting + Dynamic 共同变化。

白天：灯关、钥匙可能不在、鞋少、吧台凳整齐、桌面可为空或白水/茶/果汁。

晚上：间接灯开、钥匙回挂架、玄关多两双鞋、吧台凳可轻微错位、出现一杯酒（威士忌为主，偶尔啤酒），第二杯大多数时候没有。

## 禁止

- 重新设计房间
- 改镜头、透视、房间比例
- 随意移动或缩放主要家具
- 因局部修改整图重绘
- 自动增加纹理、写实程度、光影复杂度
- 柔和渐变、复杂反射、高光爆点
- 把 Dynamic 烘焙进 Base
- 在缺失参考图时自行搜索、生成或猜测替代母版
