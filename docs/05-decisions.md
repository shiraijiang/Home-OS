# 05 决定日志

**只追加，不修改。** 已定的事不要重新讨论。有异议先说明理由，由使用者拍板。

格式：`日期 | 决定 | 理由`

---

## 2026-08 方向

| # | 决定 | 理由 |
|---|---|---|
| 1 | 技术栈用 Google 表格 + GAS，不用 React/FastAPI/PostgreSQL/Docker | 个人项目，团队级技术栈会死在环境配置上 |
| 2 | 先做一个真的会打开的模块，让数据结构从使用里长出来；不先建抽象数据中台 | 提前抽象出来的中台，最后一定跟真实用法对不上 |
| 3 | 砍掉菜谱、食材、库存、营养、成员偏好 | 使用者九成买来吃；且这些都要求持续喂数据 |
| 4 | 凡是需要定期手动同步状态的功能一律不做 | 生死线。破一次，三个月内必死 |
| 5 | 一天只输入一次「档位 + 要不要肉」 | 减少重复决策唯一真正起作用的地方 |
| 6 | 做饭是 3 档里的一个正常选项，不是升级目标 | 避免「今天又没做饭」的隐性负担 |
| 7 | 抽牌只给一个答案，不给列表 | 给列表等于把决策还给人 |

## 交互

| # | 决定 | 理由 |
|---|---|---|
| 8 | 牌面升格用「周日集中回顾」，不用手动升格或自动统计 | 判断集中，平时记录零负担 |
| 9 | 周回顾做成首页卡片（被动出现），带跳过按钮 | 独立页会想不起来；简报是纯文本塞不下勾选 |
| 10 | 三向滑动：左删 / 右降权 / 上升权 | 单手、不用看准、牌堆在使用中自己变准 |
| 11 | 稀有度 = 罕见度，不是用心程度 | 若 SSR = 做饭，累时抽到会有压力，系统变成计分板 |
| 12 | 偶发事件只在打开的瞬间掷一次骰子 | 不制造停留压力 |
| 13 | 小生物不说话、无气泡、不评价 | 只要它不说话就永远不会烦 |
| 14 | 灵活度定位为 B：内容自己改，新模块找人写卡片 | C 会把系统变成「做系统的系统」 |
| 15 | 流水表七列固定，塞不下就单独开小表，不用 JSON 扩展列 | 表格必须肉眼可读、可手改 |
| 16 | 季节与光自动跟随现实，设置页可锁定，且必须能恢复自动 | — |

## 美术

| # | 决定 | 理由 |
|---|---|---|
| 17 | 界面隐喻为「小房间」，家具对应功能 | 位置即记忆，不用读菜单；加模块 = 加家具 |
| 18 | 房间是入口，点家具**完全换页**，不做面板升起、不做房间内浮层 | 子页面自由、实现简单；手机上浮层看不清字 |
| 19 | 视角：俯视带前倾，家具画顶面 + 正面 | 纯俯视认不出是什么家电 |
| 20 | 房间竖版 320×420，16px 一格 | 手机竖屏 1:1 |
| 21 | 只画后墙，左右切在画面边缘 | 星露谷式开阔感 |
| 22 | 材质定为清水混凝土 + 深色不发黄木 + 不锈钢 + 玻璃 + 铁艺 | 「隐居的高科技生活」 |
| 23 | 暖意全部来自光，不来自基础色 | 这套材质本身不产生暖意 |
| 24 | 翠绿是唯一高饱和；黄色只表示「现在该看这里」 | — |
| 25 | 赛璐珞平涂，无渐变 | 与像素画天然合拍，加家具成本低 |
| 26 | 全站 DotGothic16 | 味道统一，接受小字号会糊的代价 |
| 27 | 用物件表现两个人，不画人物角色 | 空房间里的痕迹比两个小人更有生活感 |
| 28 | 他的痕迹只出现在他享受过的东西上，不出现在待办上 | 否则房间变成计分板 |
| 29 | 厨房做成开放式，冰箱并入台面；岛台一体两段（上钢＝吃 / 下木＝记一笔） | 冰箱单独立着像个孤零零的按钮 |
| 30 | 落地窗在正面后墙，占大部分墙面 | 开放感；手机上第一眼应该看到风景 |
| 31 | 充电座 = 未来「隐居地切换」入口，现在不可点、不加任何提示 | 位置本身就是伏笔 |
| 32 | 猫八成时间在睡，偶尔骑扫地机器人 / 和小生物玩 | 稀有才有意思 |
| 33 | 所有动画禁用缓动，只用 linear / steps() | 像素画配缓动立刻露馅 |

## 素材

| # | 决定 | 理由 |
|---|---|---|
| 38 | 房间底图用 AI 生成，会动的物件单独生成 | 分开生成风格不统一，所以底图一次出完 |
| 39 | 不从成品图里抠 sprite | 会带背景残留、分辨率被锁死、边缘丑 |
| 40 | 生成后必须中值滤波 → 降采样 → 调色板量化 | 直接量化会把混凝土噪点映射成木头色 |
| 41 | 猫保留在底图里，扫地机器人从底图抹掉 | 猫几乎不动；机器人要移动，留下会有残影 |
