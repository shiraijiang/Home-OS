# 02 系统结构

本文件只记录已经确认的系统结构，不提前建设复杂架构。

## 当前技术方向

- Google 表格 + Google Apps Script（GAS）。
- 个人家庭系统，不采用 React / FastAPI / PostgreSQL / Docker 等团队级技术栈。
- 先做一个真实会使用的模块，再从实际使用中扩展数据结构。
- 不建设需要长期人工同步状态的数据系统。

## 当前首页结构

首页是像素房间。第一版只有三个功能入口：

| 家具 | 功能 |
|---|---|
| 岛台 | 吃：抽牌决定今天怎么解决 |
| 吧台 | 记一笔 |
| 门 | 设置 |

点击家具后完全换页，不在房间内弹出复杂浮层。

## 数据原则

- 一天只输入一次「档位 + 要不要肉」，相关模块共用。
- 流水表保持肉眼可读；现有决定为七列固定，额外需求优先独立小表，不使用 JSON 扩展列。
- 内容可以由使用者自行修改；新增模块不要求建设通用可视化搭建器。

具体数据表字段尚未在当前仓库资料中完整确认。未确认部分不得自行扩展为大型数据模型。
