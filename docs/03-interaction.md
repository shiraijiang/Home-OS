# 03 交互规格

## 首页

首页为像素房间。家具承担空间导航，不额外堆菜单。点击家具后完全换页。

当前已确认入口：

- 岛台：今天吃什么 / 抽卡
- 冰箱：私人菜谱库
- 门：设置

「记一笔」（吧台）推迟到下期（#65）。吧台仍在房间里，但不可点、不加提示。

冰箱菜谱与岛台抽卡是两个独立模块，不互相依赖。

## 吃 / 抽牌

- 一次只给一个答案，不给列表。
- 做饭只是正常选项，不是升级目标。
- 稀有度表示出现罕见程度，不表示“更努力”或“更好”。
- 日常输入收口为「今天几档 + 要不要肉」。
- 抽到「做饭」后，未来可以弱关联推荐一道菜谱，但不是当前依赖。

## 私人菜谱

- 通过冰箱进入。
- 主要用于查「上次这个东西怎么做」。
- 普通对话不自动保存；只有明确说「存菜谱」才整理入库。
- 菜谱展示以参数、容器、摆放/加工顺序和设备条件为主，不做教学式长步骤。
- 支持同菜多个做法方案，以及懒人 / 极速 / 清淡模式。

## 牌面调整

周日集中回顾，首页被动出现，可跳过。

三向滑动：

- 左：删除
- 右：降权
- 上：升权

平时不要求手动维护牌面状态。

## 随机事件

只在打开页面的瞬间掷一次，不通过弹窗、领取或任务要求用户处理。

猫、小生物、扫地机器人之间可以发生低频随机互动。小生物不说话、不评价、不提醒。

## 时间与季节

季节与光默认跟随现实自动变化。设置页允许临时锁定，但必须可以恢复自动。

时间变化还会通过 Dynamic 层的生活痕迹体现，具体见 `04-art.md`。

## 动画

像素动画不使用缓动；采用 linear 或 steps()。
