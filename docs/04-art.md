# 04 美术规格

本文件用于约束 Home-OS 首页场景的持续制作。任何后续局部修改都不得重新解释整个房间。

## 视觉母版

当前已选定一张「大房间概念图」作为空间构图母版。它只负责定义：

- 镜头、透视
- 房间外轮廓、墙体、门窗
- 开放式厨房、独立冰箱、岛台
- 玄关、鞋柜
- 衣架 / 开放式置物架
- 卧室开放入口
- 右侧玻璃结构
- 主要家具位置、比例和整体空间关系

后续禁止因为局部修改重新设计整个房间，尤其不得改变镜头、透视、房间比例、主要家具位置和比例。

优先采用局部编辑、分层和独立 sprite，不连续整图重绘。

## 像素美术基准

- 目标：high-detail pixel illustration，不是低分辨率滤镜。
- 像素粗度比原始大房间概念图明显粗一档。
- 直线、柜门、窗框应能看出像素阶梯。
- 木材不画大量连续木纹。
- 混凝土和地砖不铺高频细碎噪点。
- 植物使用像素簇，不逐叶精描。
- 金属、玻璃只用少量高光块表达体积。
- 小物件允许明显简化。
- 阴影用明确色块，减少柔和渐变。
- 后续修改不得逐轮增加纹理、写实程度和像素密度。
- Dynamic sprite 必须和 Base 使用同一像素密度。

另有一张「小房间像素参考图」，只负责像素颗粒、轮廓阶梯感、信息密度、材质简化程度、植物像素簇和小物件简化程度；不得把其户型或家具布局带入 Home-OS。

## 场景尺寸

- logical scene：320 × 420
- working scale：4×
- working master：1280 × 1680
- target：mobile portrait
- 320×420 是逻辑尺寸，不是手机物理输出分辨率。
- 前端等比例显示，不拉伸房间。
- UI 与 pixel scene 分离。
- 点击热区绑定 logical scene 坐标。
- 长屏优先使用 UI 区域 / 留白适配。
- 第一版不专门设计横屏。
- 16px grid 只作为建筑和固定家具辅助布局单位，Dynamic 不必严格按格移动。

## 基础材质与色彩

- 赛璐珞式平涂，无渐变。
- 材质：清水混凝土、深色不发黄木、不锈钢、玻璃、铁艺。
- 暖意来自光，不来自基础材质色。
- 翠绿是环境中唯一高饱和色。
- 黄色只用于需要注意的状态以及黄色小精灵，不作为大面积环境色。
- 项目统一调色板，但色数暂不锁定；需在 Base 出图后统一测试再确定。
- 不允许每张图临时扩色。

## 分层

### Base / 固定层

长期不移动的建筑、家具和固定装饰，包括：

- 墙、地面、门窗
- 厨房主体、独立冰箱、岛台 / 吧台
- 玄关和鞋柜本体
- 衣架 / 开放式置物架本体
- 卧室入口结构
- 右侧玻璃结构
- 扫地机器人充电口 / 充电座
- 盆栽（第一版固定）
- 鱼缸主体和固定造景
- 猫用品中的固定物件：食盆、水碗、猫窝、小型抓板 / 抓柱、玩具收纳篮 / 盒
- 水槽旁一瓶固定洗洁精
- 冰箱门少量固定贴饰（如已有母版则保持，不继续增加）
- 冰箱顶最终确认后的固定装饰

猫用品贴墙自然摆放，不一字排开，不做大型猫爬架，不形成强烈宠物专区。

当前右侧不增加额外小矮柜，也不在地上靠墙摆画。

### Dynamic / 动态层

不得烘焙进 Base：

- 猫
- 扫地机器人
- 黄色小精灵
- 钥匙
- 鞋
- 衣服
- 随身包
- 饮料、酒、杯子、食物
- 散落猫玩具
- 其他临时生活物件
- 电子设备的具体动态时间显示

猫是居民，不是系统助手；不承担提醒、任务、饥饿值、好感度、健康值或每日照顾机制。

黄色小精灵为 Dynamic，主色黄色。氛围可以参考《星露谷物语》祝尼魔带来的安静小生物感，但不复制具体外形。它可随机出现、消失、活动、和猫互动；不说话、不提醒、不发奖励、不要求领取。

### Environment / 环境层

窗外环境独立于 Base，承载：

- 天空
- 远景 / 水面 / 城市等具体窗外景色
- 天气
- 季节变化

Base 不烘焙具体窗外景色。

### Lighting / 光照层

Base 应为中性光照版本：

- 室内灯关闭
- 无方向性阳光
- 无窗格投影
- 无长投影
- 无明显时间感
- 只保留最轻的接触阴影，用来说明物体与地面的支撑关系

具体早朝、白天、夕方、夜晚的自然光、室内灯和光晕全部拆到 Lighting。

时间变化不能只加整图滤镜，必须由 Environment + Lighting + Dynamic 生活痕迹共同表现。

白天倾向：

- 间接照明关闭
- 钥匙不在挂架
- 玄关鞋较少
- 吧台凳整齐
- 桌面可有白水、茶、果汁或为空

晚上倾向：

- 间接照明开启
- 钥匙回到挂架
- 玄关多两双鞋
- 吧台凳允许轻微错位
- 固定出现一杯酒，以威士忌为主、偶尔啤酒
- 第二杯大多数时候没有，出现时可以是不同鸡尾酒
- 一次只需出现杯，不固定画酒瓶

床不做昼夜整理 / 凌乱变化。窗帘和百叶第一版固定，不每日自动开合。

### Seasonal / 季节层

季节变化主要通过 Environment + Lighting + 少量环境表现完成，不重新生成整个房间。

- 室内固定家具不随四季重新设计。
- 室内盆栽第一版固定。
- 鱼缸长期保留白沙 + 糖果色造景的夏天感，不随季节重做。

## 鱼缸

鱼缸主体与造景可固定在 Base。视觉方向保持小型景观装置感：白沙、少量糖果色石 / 造景，不做过密水草和高维护季节变化。

## 猫与扫地机器人

猫本体 Dynamic。时间只改变状态概率：早朝偏睡、白天大部分睡、夕方活动概率提高、晚上更活跃，不建立复杂模拟。

扫地机器人本体 Dynamic，充电座 Base 且靠墙。

允许偶发：机器人轻轻碰到地面上的猫后停一下 / 转向，猫可能不理或挪两步。不做复杂物理模拟。

稀有事件：猫四脚站在正在移动的扫地机器人上保持平衡。概率明显低，只在机器人运行时发生；不弹成就、不要求点击。

## 扫地机器人充电口 / 隐居地入口

充电口本体属于 Base，扫地机器人属于 Dynamic。

充电口同时是未来「隐居地」入口的物理位置。当前版本：

- 看起来就是正常充电设施
- 不可点击
- 不加文字、发光、箭头等入口提示
- 不为了未来功能改变现有构图

未来启用隐居地时，从这个既有位置扩展交互。

## 冰箱顶装饰

冰箱顶装饰属于 Base，需要固定具体物件、数量、位置和轮廓。当前只确认「必须明确设计且不能由模型自由发挥」，具体组合尚未确认。在确认前，任何生成 / 修改不得自行新增复杂摆件。

## 参考图管理

所有真正承担视觉约束的图片必须入库到 `assets/reference/`，不能只在聊天里用“那张图”指代。

至少保留：

- `scene-master.*`：大房间概念图；只约束构图、镜头、透视、家具比例和位置。
- `pixel-style-reference.*`：小房间像素参考图；只约束像素粗度、边缘语言和信息密度。

在图片真正入库之前，执行者不得自行找替代图、生成替代母版或根据文字重建参考图。

## AI 美术修改硬性规则

- 每次修改优先局部编辑。
- 不改变镜头、透视、房间外轮廓和主要家具位置 / 比例。
- 不因局部修改重新解释整个场景。
- 不自动增强细节、光影、材质纹理和写实程度。
- 新增会动的物件优先做独立资源。
- Base 制作阶段禁止方向性阳光、具体窗外景色、开着的灯和光晕、动态物件、设备动态显示、高光爆点、复杂反射、细密纹理和渐变。
