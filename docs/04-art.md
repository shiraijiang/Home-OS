# 04 美术规格

本文件用于约束 Home-OS 首页场景的持续制作。任何后续局部修改都不得重新解释整个房间。

## 视觉方向

- 高细节 pixel illustration，不是低分辨率滤镜。
- 赛璐珞式平涂，无渐变。
- 视角为俯视带前倾，家具同时能看到顶面和正面。
- 画布基准：竖版 320×420，16px 一格。
- 只画后墙，左右在画面边缘切断。
- 落地窗位于后墙并占主要面积。
- 材质：清水混凝土、深色不发黄木、不锈钢、玻璃、铁艺。
- 暖意来自光，不来自基础材质色。
- 翠绿为唯一高饱和环境色；黄色仅用于需要注意的状态。

## 连续性规则

选定视觉母版后，后续修改必须保持：

- 镜头
- 透视
- 房间边界
- 家具比例
- 主要家具位置
- 整体像素粗细与细节密度

局部问题优先局部修改或分层处理。禁止因为修改一个物件重新生成整套构图。

## 分层

### Base / 固定层

长期不移动的建筑、家具和固定装饰，包括：

- 墙、地面、落地窗
- 厨房主体、冰箱、岛台/吧台等固定家具
- 扫地机器人充电口/充电座
- 盆栽（当前允许固定）
- 鱼缸主体与内部固定造景
- 冰箱顶最终确认后的固定装饰

### Dynamic / 动态层

不得烘焙进 Base：

- 猫
- 扫地机器人
- 小生物/小精灵
- 钥匙
- 鞋
- 衣服
- 饮料、酒和杯子
- 其他需要出现/消失/移动的生活痕迹

猫是居民，不是系统助手；不承担提醒、任务、好感度或养成机制。

### Lighting / 光照层

时间变化不能只做整张图滤镜。至少同时考虑：

- 窗外环境
- 自然光方向与强度
- 室内照明开关
- 房间生活痕迹

白天倾向：间接照明关闭；钥匙可能不在挂架；玄关鞋较少；桌面可有白水、茶、果汁或为空。

晚上倾向：间接照明开启；钥匙回到挂架；玄关多两双鞋；固定出现一杯酒，以威士忌为主、偶尔啤酒；第二杯多数时候没有，出现时可为不同鸡尾酒。吧台凳允许轻微错位。

### Seasonal / 季节层

春夏秋冬主要通过窗外环境、光线和少量环境变化表达，不重新设计房间。

## 扫地机器人充电口

充电口本体属于 Base，扫地机器人属于 Dynamic。

充电口同时是未来「隐居地」入口的物理位置。当前版本：

- 看起来就是正常充电设施
- 不可点击
- 不加文字、发光、箭头等入口提示
- 不为了未来功能改变现有构图

未来启用隐居地时，从这个既有位置扩展交互。

## 冰箱顶装饰

冰箱顶装饰属于 Base，需要固定具体物件、数量、位置和轮廓。当前只确认「必须明确设计且不能由模型自由发挥」，具体组合尚未确认。在确认前，任何生成/修改不得自行新增复杂摆件。

## 参考图管理

所有真正承担视觉约束的图片必须入库到 `assets/reference/`，不能只在聊天里用“那张图”指代。

建议至少保留两类：

- `scene-master.*`：构图、镜头、透视、家具比例和位置的视觉母版。
- `pixel-style-reference.*`：只约束像素粗细、边缘语言和细节密度，不用于改变母版构图。

图片未入库时，文档不得声称对应参考已经可供执行者读取。
