# home-os

一个个人用的家庭辅助系统。目的只有一个：**减少重复决策，减少能量损耗。**

界面是一个像素风的小房间，点房间里的家具进入各个功能。

---

## 当前状态

设计阶段。第一版范围已锁定，尚未开工。

- 已完成：目标与原则、系统结构、交互机制、美术方案、房间底图
- 未开始：任何代码
- 使用者：一个人（以我为主），不需要多人协作功能

---

## 给协作的 AI 的说明

接手前请**按顺序**读完 `docs/` 下的六份文件，尤其是 `05-decisions.md`。

三条纪律：

1. **不要重新讨论已经定死的事。** 决定日志里有的，直接照做。有异议先说明理由，由我拍板，不要自行推翻。
2. **不要扩大范围。** `01-spec.md` 里写了明确不做的东西，那些是刻意砍掉的，不是遗漏。
3. **不要加需要人工维护状态的功能。** 这是整个系统的生死线，见 `01-spec.md`。
