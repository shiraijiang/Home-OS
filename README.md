# home-os

一个个人用的家庭辅助系统。目的只有一个：**减少重复决策，减少能量损耗。**

界面是一个像素风的小房间，点房间里的家具进入各个功能。

**第一版就是一个吃饭系统**：抽卡负责「今天怎么解决」，菜谱库负责「上次这个怎么做」。先把一个领域做透，其余功能都在下期。

---

## 当前状态

设计资料整理与美术规格补全阶段，业务代码尚未开工。

当前已确认：

- 目标、范围和低维护原则

- 独立私人菜谱库及菜谱格式
- 美术连续性、分层、时间 / 季节规则
- 未来隐居地入口位置
- Default 空间母版、像素语言参考图与 Alt-01 备选画风参考均已入库

当前仍缺：

- 冰箱顶固定装饰最终组合
- Base 完成后的正式调色板
- AI 出图后的正式像素处理脚本（尚未开始写代码）

使用者：一个人。不建设多人协作功能，也不建设需要长期手动维护状态的大系统。

## 给协作 AI 的说明

接手前按顺序读：

1. `CLAUDE.md` / `AGENTS.md`（存在时）
2. `docs/01-spec.md`
3. `docs/02-system.md`
4. `docs/03-interaction.md`
5. `docs/04-art.md`
6. `docs/05-decisions.md`
7. `docs/06-backlog.md`

其中 `05-decisions.md` 是历史决定日志。旧决定被后续编号明确覆盖时，以后续决定为准；现行执行规格以对应 docs 文件为准。

三条纪律：

1. 不重新讨论已经定死的事；有冲突先指出，由使用者拍板。
2. 不扩大范围，尤其不增加需要人工持续维护状态的功能。
3. 美术修改必须保持母版连续性，不因局部修改重新设计整个房间。
